# 1호기: AI 일러스트 수집형 비동기 경쟁 슬라이딩 퍼즐 (SPEC.md)

## 1. 프로젝트 개요
- **엔진:** Unity (2D / UGUI 기반)
- **목표:** 오프라인 플레이 완벽 지원 + 온라인 연결 시 비동기 글로벌 랭킹 경쟁을 유도하는 AI 일러스트 수집형 슬라이딩 타일 퍼즐 게임.
- **수익 모델:** 중간맛 광고(보상형 힌트/되돌리기, 2~3판당 전면 광고) + 광고 제거 인앱 결제(IAP).
- **그리드 규격:** **3x3** 입문 난이도부터 시작하여 3x4, 4x4, 4x5, 5x6 ... 최대 **6x8 (48칸)** 그리드까지 유동적 확장 지원.
- **타일 모양 (추가 확정):** 모든 타일은 정사각형이며 직사각형 타일은 사용하지 않음. 보드는 화면 안에 맞게 축소/확대함.
- **이미지 비율 처리 (Phase 1 기본안):** 원본과 보드 비율이 다르면 중앙 기준으로 잘라 채움(Center Crop). 원본 텍스처는 변경하지 않으며, 도감에서 원본 전체 감상은 별도로 제공할 수 있음.
- **일러스트 리소스 경로:** `Assets/Resource.art/Puzzle_images`
  - 주의: 폴더명이 `Resources`가 아닌 `Resource.art`이므로 런타임 `Resources.Load` 대신 `StageData` (ScriptableObject)에서 `Texture2D`를 직접 직렬화 참조하거나, 에디터 스크립트(`AssetDatabase`)를 통해 해당 경로의 이미지들을 `StageData`에 자동 매핑하도록 설계함.

## 2. 핵심 알고리즘 및 조작 메커니즘

### 2.1. RawImage UV 자동 분할 및 빈 칸(Blank) 규칙
- **런타임 UV 분할 (RawImage 기반):**
  - 별도의 스프라이트 에셋 분할 없이, `StageData`에 등록된 원본 `Texture2D` 1장을 각 타일의 `RawImage` 컴포넌트에 할당하고 `uvRect`를 계산해 조각을 표시함.
  - **UV 좌표 계산 공식 (상하 반전 방지 필수):**
    - 전체 열 개수 `cols`, 전체 행 개수 `rows`일 때:
    - `tileWidth = 1f / cols`, `tileHeight = 1f / rows`
    - 정답 위치가 좌측 상단 기준 `(col, row)` (단, `0 <= col < cols`, `0 <= row < rows`)인 타일의 UV는:
    - `uvX = col * tileWidth`
    - `uvY = 1f - ((row + 1) * tileHeight)` (Unity UV 원점은 좌측 하단이므로 Y축 반전 계산 필수)
    - `uvRect = new Rect(uvX, uvY, tileWidth, tileHeight)`
    - 중앙 크롭 적용 시 먼저 보드 비율(`cols / rows`)에 맞는 원본 UV 영역 `sourceRect`를 계산하고, 위 UV를 해당 영역 안으로 변환함. 모든 타일과 마지막 조각에 동일한 영역을 사용하여 상하 반전과 이미지 왜곡을 방지함.
- **빈 칸(Blank) 위치 및 클리어 연출:**
  - 정답 기준 빈 칸의 위치는 항상 **우측 하단 마지막 칸 (`col = cols - 1, row = rows - 1`, 마지막 인덱스)**으로 고정함.
  - 플레이 중에는 마지막 칸이 비어 있으며, 모든 타일이 정답 위치에 도달해 **클리어하는 순간 우측 하단 빈 칸에 숨겨져 있던 마지막 일러스트 조각이 부드럽게 나타나며(Fade-in) 타일 간격과 숫자 가이드가 사라져 보드에 사용한 일러스트 영역을 빈 칸 없이 보여줌.** 중앙 크롭 시 원본의 바깥쪽 일부는 보드에 표시되지 않음.

### 2.2. 100% 풀 수 있는 결정론적 역방향 셔플 (Method A)
- **문제 해결:** 무작위 배열 시 발생하는 '풀 수 없는 퍼즐(Inversion Parity 오류)'을 원천 차단하고, 모든 유저에게 동일한 셔플 판을 제공해 공정한 경쟁을 유도함.
- **구현 방식:**
  1. 각 스테이지(`StageData`)는 고유한 `ShuffleSeed(int)`와 `ShuffleCount(int)`를 가짐.
  2. 퍼즐 생성 시 정답(완성) 상태에서 시작함.
  3. `Random.InitState(ShuffleSeed)`를 적용한 뒤, 빈 칸(Blank)과 인접한 유효 타일 중 하나를 골라 빈 칸과 위치를 바꾸는 합법적 이동을 `ShuffleCount`만큼 역으로 수행함 (단, 직전에 이동했던 타일을 즉시 되돌리는 무의미한 왕복 이동은 제외).
  4. 섞기 완료 후 혹시라도 완성 상태와 동일하다면 추가로 유효 이동을 수행해 완성되지 않은 시작판을 보장함. 최소 풀이 난이도 보장은 별도 검증 사항임.
  5. 셔플 중 인접 후보 순서를 상/우/하/좌로 고정하고, 전역 난수 상태를 저장했다가 셔플 후 복구함. 스테이지 ID 및 셔플 버전을 함께 보관함.

### 2.3. 모바일 최적화 조작 (최대 6x8 대응)
- **다중 타일 한 번에 밀기 (Multi-push / Line Slide):**
  - 기본값(Default): **ON**
  - **ON 상태:** 빈 칸과 같은 행(Row) 또는 같은 열(Column)에 있는 타일을 터치하면 그 사이에 끼어 있는 타일들이 빈 칸 쪽으로 한 번에 밀려 이동함.
  - **OFF 상태:** 빈 칸과 바로 맞닿은 상하좌우 인접 타일 1개만 이동 가능함.
- **턴(Move Count) 산정 및 되돌리기(Undo) 기준:**
  - 다중 타일 밀기로 여러 개의 타일이 한 번에 이동하더라도 **1턴(1 Move)**으로 산정함.
  - 되돌리기(Undo) 실행 시에도 직전 1턴에 움직였던 타일 묶음 전체가 한 번에 이전 위치로 복구됨.
  - **추가 확정:** Undo 자체는 이동 횟수에 포함하지 않으며, 실제 Undo 사용 횟수(`UndoUsed`)를 별도로 기록함. 기본 사용 가능 횟수는 **3회**이고 소진 후 보상형 광고로 충전 가능함.
  - **Phase 1 기본안:** 기존 이동 횟수는 누적 유지하고, 한 판 시작/다시하기 시 Undo 3회를 지급하며 사용 기록을 초기화함. 광고 보상 완료 1회당 3회를 충전함(충전량은 Inspector에서 조정 가능).
  - 이력이 없거나 이동 중/중단/클리어 상태인 경우 Undo를 수행하지 않으며, 실패한 요청은 횟수를 소모하지 않음.
  - 광고 요청/취소/단순 닫기는 보상을 지급하지 않음. 광고 SDK의 보상 완료 콜백만 충전하며 중복 콜백 및 이전 판의 콜백은 무시함. 실제 SDK는 Phase 4에서 연결함.
- **타일 이동 연출 전환 (Slide Lerp vs Instant):**
  - 설정값에 따라 타일 이동 시 **부드러운 슬라이드 이동(Slide Lerp, 약 0.08~0.1초)**과 **즉시 순간이동(Instant Snap, 0초)**을 실시간으로 전환할 수 있어야 함. (다중 타일 밀기 시에도 동일하게 적용)
- **숫자 가이드 토글 (Number Overlay):**
  - 일러스트 조각 위에 타일의 원래 정답 순서 번호(1, 2, 3...)를 반투명하게 켜고 끌 수 있는 인게임 토글 제공.

## 3. UI 화면 구조 및 치팅 방지(Anti-Cheat) 설계

### 3.1. 전체 화면 흐름
1. **메인 로비 (Lobby):** 난이도 탭(3x3 ~ 6x8), 스테이지 선택 카드, 도감/랭킹 진입 버튼.
2. **인게임 플레이 화면 (In-Game HUD):**
   - **좌측 상단:** 일시정지(Pause) 버튼
   - **상단 중앙/우측:** 스테이지 정보, 실시간 이동 횟수(Move Count), 경과 시간 타이머(Timer)
   - **중앙:** 동적 그리드 퍼즐 보드 (Board)
   - **하단 컨트롤 바:** 숫자 가이드 ON/OFF 토글, 되돌리기(Undo), 원본 이미지 미리보기(누르고 있는 동안만 표시)
3. **일시정지 및 설정 팝업 (Pause Modal) - ★핵심 요구사항:**
   - 좌측 상단 중단 버튼 클릭 시 즉시 타이머가 정지되며 팝업 호출.
   - **퍼즐 가림막 (Blind Mask):** 중단 상태에서 시간을 멈춰놓고 퍼즐 경로를 계산하는 치팅을 막기 위해, 중단 즉시 퍼즐 보드 전체를 100% 불투명하게 덮어버리는 가림막 패널 활성화.
   - **원본 미리보기 차단:** 중단 상태(및 재개 카운트다운 중)에서는 퍼즐 이미지 미리보기 기능 완전 비활성화.
   - **재개 시 3-2-1 카운트다운:** '계속하기(Resume)' 클릭 시 팝업은 닫히지만 **가림막(Blind Mask)은 유지된 상태**에서 화면 중앙에 `3 -> 2 -> 1` 카운트다운이 진행됨. 카운트다운이 끝나는 순간 가림막이 걷히며 타이머와 조작이 동시에 재개됨.
   - **인게임 설정 항목 (`PlayerPrefs` 연동 및 즉시 반영, 총 4종):**
     1. **배경음 (BGM):** ON / OFF (`PREF_BGM`, 기본 ON)
     2. **효과음 (SFX):** ON / OFF (`PREF_SFX`, 기본 ON)
     3. **줄 통째로 넘기기 (Multi-push):** ON / OFF (`PREF_MULTIPUSH`, 기본 ON)
     4. **타일 이동 애니메이션 (Slide Lerp / 순간이동):** ON(부드러운 슬라이드) / OFF(즉시 순간이동) (`PREF_SLIDE_ANIM`, 기본 ON)
   - **하단 버튼:** 계속하기(Resume), 다시하기(Restart), 로비로 나가기(Lobby).
4. **클리어 결과 팝업 (Result Modal):**
   - 우측 하단 빈 칸이 채워지며 완성된 AI 일러스트 전체 감상 연출 후 팝업 표시.
   - 소요 시간 및 총 이동 횟수 표시, 비동기 랭킹 상위 퍼센트(%) 피드백.
5. **일러스트 도감 (Gallery):**
   - 클리어한 스테이지의 AI 일러스트 해금(미해금 시 자물쇠/실루엣 처리) 및 전체화면 감상.

## 4. 백엔드 및 데이터 파이프라인
- **오프라인 우선 (Offline-First):** 모든 스테이지 진행도, 최고 기록(최소 턴, 최단 시간), 해금된 도감 데이터, 설정값 4종은 로컬(JSON 또는 PlayerPrefs)에 즉시 저장되어 인터넷 없이도 100% 플레이 가능.
- **온라인 경쟁 연동 (UGS + GPGS/Apple Game Center):**
  - Unity Gaming Services (Authentication & Leaderboards)를 사용하여 커스텀 리더보드 UI 구현 및 구글/애플 계정 연동 지원.
  - 경쟁 지표 3종: ① 스테이지별 최소 턴 수, ② 스테이지별 최단 클리어 시간, ③ 총 수집(클리어) 일러스트 개수.

## 5. 단계별 개발 로드맵 (Codex CLI 작업 순서)
- **샘플 이미지 표현 반영:** 실제 플레이 씬은 SampleScene의 첫 원본 이미지, 슬라이스 외곽 프레임, 15px 패딩, 1px 타일 간격을 사용. 프레임은 현재 보드의 행/열 및 화면 크기에 맞게 조절. 고정 5x9 레거시 로직 대신 기존 3x3~6x8 UV 분할/셔플/Undo를 유지하며 숫자 가이드는 신규 사용자에게 기본 OFF(저장 설정 우선).
- **Phase 1 (데이터 및 코어 보드 로직):**
  - **추가 확정:** 별도 테스트 씬 연결 포함. 기존 프로토타입은 보존하며, 3x3~6x8 및 클리어 연출 확인용 1회 이동 스테이지를 제공함.
  - `StageData.cs`: ScriptableObject (`Assets/Resource.art/Puzzle_images` 내 `Texture2D` 참조, 가로/세로 행렬 크기, 셔플 시드 및 횟수).
  - `PuzzleTile.cs`: 개별 타일 컴포넌트 (`RawImage` UV 분할 적용, 숫자 가이드 텍스트, 코루틴 기반 Slide Lerp 및 Instant 이동 처리).
  - `BoardManager.cs`: NxM(최대 6x8) 동적 타일 배치, Method A 시드 기반 역방향 셔플, 다중 타일 밀기(1턴 처리) 및 Undo 스택, 클리어 판정 및 마지막 조각 복원 연출.
  - `PuzzleBoardState.cs`: 정수 배열 기반 상태 및 셔플/이동/Undo 기록. 렌더링과 분리하여 자동 테스트함.
  - 테스트 씬의 `TEST reward +3` 버튼은 에디터/Development Build 전용 광고 보상 모의 처리이며 실제 광고를 재생하지 않음.
- **Phase 2 (인게임 UI 및 일시정지/설정 시스템):**
  - `SettingsManager.cs`: 4대 설정(BGM, SFX, 다중 밀기, 이동 애니메이션) 로드/저장 및 변경 이벤트. 기존 PlayerPrefs 키 유지.
  - `PuzzleGame.cs`: 기존 게임 흐름에 타이머, 턴 카운트, 일시정지 가림막(Blind Mask), 미리보기 차단, 3-2-1 재개 루프를 통합. 별도 GameManager/UIManager로 중복 구현하지 않음.
  - `PauseSettingsUI.cs`: 기존 일시정지 패널에 4종 설정과 계속하기/다시하기를 연결. 앱 포커스 상실 시 재개 카운트다운을 취소하고 일시정지 유지.
  - `PuzzleAudio.cs`: BGM/SFX 독립 채널 및 즉시 음소거. 기본 합성 배경음/이동음/클리어음을 제공하며 Inspector의 AudioClip으로 교체 가능.
  - 클리어 시 최소 이동 횟수, 최단 시간, 클리어 여부를 로컬 저장. 로비 이동 버튼은 Phase 3의 실제 로비와 함께 연결.
- **Phase 3 (로비, 일러스트 도감 및 모바일 전용 화면 대응 — 예정):**
  - 스테이지 해금 흐름, 갤러리 UI 및 원본 전체화면 뷰어.
  - 설정에서 **세로 플레이 / 가로 플레이**를 명시적으로 선택하고 선택값을 저장하여 재실행 시 복원. 기본값은 세로 플레이.
  - 선택한 방향으로 모바일 화면 방향을 적용하며, 세로/가로 전용 HUD·보드·설정·로비·갤러리 레이아웃을 제공. 단순 화면 회전/레터박스로 대체하지 않음.
  - 다양한 휴대폰/태블릿 해상도 및 종횡비, 노치/홈 인디케이터 Safe Area 대응. 정사각형 타일 유지, 버튼 잘림·겹침 및 터치 영역 축소 방지.
  - 플레이 도중 방향 변경은 일시정지 상태에서 적용하고 보드 배열·이동 횟수·Undo·시간을 보존. 3-2-1 이후 재개.

## 추가 이미지 스테이지 등록
- 기존 7개 스테이지의 ID와 순서를 유지하고 새 이미지 21개를 추가하여 총 28개를 플레이 씬에 연결.
- GIF 3개와 WebP 1개는 첫 프레임 PNG를 사용하며 원본 파일을 보존. GIF/PNG가 함께 있으면 PNG만 새 스테이지로 등록.
- Unity 메뉴 `Puzzle > Add New Images To Stages`로 이미지 폴더의 미등록 텍스처를 추가. 재실행 시 기존 이미지와 스테이지 ID를 중복 생성하지 않음.
- 보드 크기는 원본 해상도의 종횡비로 결정. 비율 0.9~1.1은 3x3, 세로형은 3x4~3x8, 가로형은 4x3~6x3 중 중앙 크롭 손실이 가장 적은 구성을 사용. 동일 비율이면 해상도가 달라도 같은 보드를 사용하며 정사각형 타일을 유지.
- 파일명은 `puzzle_001_silver_armor`처럼 번호와 내용으로 통일. PNG로 변환한 원본 GIF/WebP도 같은 이름을 사용하고 확장자로 구분. 파일 번호는 이미지 ID이며 스테이지 번호와 별개.
- 임시 배경: `Assets/Resource.art/Backgrounds/bg_puzzle_misty_forest_temp.png`. 화면 비율에 맞춰 채우고 중앙 크롭하며 터치 입력을 가로채지 않음.
